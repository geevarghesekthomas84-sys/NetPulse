About NetPulse

NetPulse is a free learning tool that makes computer networking visible. It was built by Geevarghese K Thomas so that students, teachers and engineers can watch protocols work, inspect real packets and practise network configuration without installing anything.

Who it is for

Students preparing for Network+ or CCNA, teachers who want a shareable link for each protocol, and anyone curious about how the internet works.

Privacy

NetPulse runs entirely in your browser. There are no accounts, no analytics and no tracking. Your settings and progress are stored only on your own device, and any .pcap file you open is read locally and never uploaded.

Open source and contact

The source code is on GitHub under the Apache 2.0 licence. To report a problem or suggest a protocol, open an issue there.
