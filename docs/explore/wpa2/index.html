Wi-Fi WPA2 (IEEE 802.11i WPA2-PSK (4-Way Handshake)): how it works, step by step

What is Wi-Fi WPA2?

WPA2 secures Wi-Fi networks using a 4-way EAPOL-Key handshake between the client and Access Point to prove both know the PSK without ever transmitting it over the air, deriving fresh AES-CCMP encryption keys.

What is Wi-Fi WPA2, in simple words?

Even if two friends share a secret password, they don’t shout it in a crowded room. Each picks a random number, mixes it with the password, and checks if the other gets the same secret result.

How does Wi-Fi WPA2 work, step by step?

  1. 802.11 Auth & Association

    Probe, Open Auth & Association Request. Station discovers SSID via Beacon/Probe and associates with the Access Point.

  2. 4-Way Handshake Msg 1 (ANonce)

    AP sends random ANonce to STA. Both share PMK (from PSK); AP sends ANonce so STA can derive the session PTK.

  3. 4-Way Handshake Msg 2 (SNonce + MIC)

    STA replies with SNonce & MIC. STA computes PTK, returns SNonce plus a Message Integrity Code proving it knows the password.

  4. Msg 3 & 4 + Encrypted Traffic

    Install GTK/PTK & encrypt 802.11 frames. AP delivers Group Temporal Key (GTK), STA confirms Msg 4, and AES-CCMP data flows.

Is Wi-Fi WPA2 secure? Common attacks and defenses

  • KRACK & Offline PMKID/Handshake Cracking. Capturing EAPOL Msg 1–2 allows offline GPU dictionary attacks against weak Wi-Fi passphrases; KRACK replays Msg 3 to reset nonces. Defense: Use long random passphrases (16+ chars) or upgrade to WPA3-SAE (Dragonfly) which resists offline dictionary attacks.

Frequently asked questions about Wi-Fi WPA2

Does the WPA2 4-way handshake ever send the Wi-Fi password across the air?

Answer: No, it sends ANonce/SNonce and a cryptographic MIC. The PSK never crosses the air; peers prove knowledge of PMK via a MIC over the nonces.

Which cipher suite is mandatory in WPA2?

Answer: AES-CCMP. WPA2 mandates AES-CCMP for strong confidentiality and integrity.

What EtherType carries WPA2 4-way handshake frames?

Answer: 0x888E (EAPOL). EAP over LAN (EAPOL) uses EtherType 0x888E.

Why does WPA2 derive a fresh PTK per session using ANonce and SNonce?

Answer: So every device and session uses unique encryption keys. Random nonces guarantee unique Pairwise Transient Keys even when everyone shares one PSK.

Which protocol improves upon WPA2-PSK to stop offline dictionary cracking?

Answer: WPA3-SAE. WPA3 Simultaneous Authentication of Equals (SAE) replaces static PSK key derivation.
