SMB (Server Message Block (SMBv3 File Sharing)): how it works, step by step

SMB (port 445) powers Windows and NAS network file shares, printers, and named pipes. SMBv3 adds AES-128-GCM encryption, multichannel throughput, and signing to block relay attacks.

SMB explained simply

SMB makes a folder on a remote server look like a normal hard drive letter (Z:) on your own computer.

Devices in the SMB exchange

  • Client (host, 192.168.1.10)
  • Firewall (NAT) (firewall, 192.168.1.1)
  • File Server (file server, 203.0.113.20)

How SMB works, step by step

  1. Negotiate Dialect (SMBv3.1.1)

    Agree encryption & signing capabilities. Client and File Server negotiate SMB 3.1.1 with preauth integrity and AES-GCM.

  2. Session Setup & Tree Connect

    Authenticate + mount \\filesrv\shared. Client authenticates via Kerberos/NTLMv2 and connects to the shared folder tree.

  3. Create, Read & Close

    Encrypted file read over port 445. Client opens report.xlsx and reads encrypted SMB3 data chunks.

What SMB looks like on the wire

This is the packet sequence NetPulse replays for a typical SMB exchange. Open the animation to inspect each one.

  1. SMB3 from 192.168.1.10 to 203.0.113.20: Negotiate Protocol Request (Dialects: 3.0, 3.1.1) (214 bytes)
  2. SMB3 from 203.0.113.20 to 192.168.1.10: Negotiate Response (Dialect=3.1.1, Cipher=AES-128-GCM) (248 bytes)
  3. SMB3 from 192.168.1.10 to 203.0.113.20: Session Setup Request (Kerberos Ticket) (640 bytes)
  4. SMB3 from 203.0.113.20 to 192.168.1.10: Session Setup OK + Tree Connect \\filesrv\shared (180 bytes)
  5. SMB3 from 192.168.1.10 to 203.0.113.20: Encrypted Create & Read Request (report.xlsx) (196 bytes)
  6. SMB3 from 203.0.113.20 to 192.168.1.10: Encrypted Read Response (4096 Bytes) (1460 bytes)

SMB security notes

  • SMB Relay & WannaCry (SMBv1 EternalBlue). Legacy SMBv1 had critical RCE flaws and unsigned SMBv2 allows NTLM credential relay. Defense: Disable SMBv1 completely, block port 445 at internet perimeters, and require SMB Signing + Encryption.

Test yourself on SMB

Which TCP port does modern SMB (direct-hosted) use?

Answer: 445. Modern SMB runs directly over TCP port 445.

Which SMB security setting prevents NTLM SMB Relay attacks?

Answer: Requiring SMB Signing. SMB Signing cryptographically signs every SMB packet so relayed tokens fail.

Why should SMBv1 always be disabled?

Answer: It lacks modern encryption and suffered catastrophic RCE flaws like EternalBlue. SMBv1 is deprecated and insecure; SMBv3 provides modern security and performance.
