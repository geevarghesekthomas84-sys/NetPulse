BGP (Border Gateway Protocol (BGP-4)): how it works, step by step

What is BGP?

BGP is the exterior routing protocol that glues together the global internet’s Autonomous Systems (ISPs, clouds, CDNs) by exchanging reachable IP prefixes and AS_PATH loop-free attributes.

What is BGP, in simple words?

BGP is how postal hubs across different countries tell each other: "To reach ZIP code 203.0.113.0/24, pass the letter through Hub 64510 and Hub 64511."

Which devices take part in a BGP exchange?

  • ISP Router AS64500 (router, 198.51.100.1)
  • Transit AS64510 (router, 198.51.100.2)
  • Hosting AS64511 (router, 203.0.113.1)

How does BGP work, step by step?

  1. TCP Port 179 Session

    BGP peers establish TCP connection. Autonomous Systems open a reliable TCP session on port 179 before exchanging BGP messages.

  2. OPEN & KEEPALIVE

    Peers negotiate ASN & capabilities. AS64500 and AS64510 exchange OPEN messages with hold timers and confirm with KEEPALIVE.

  3. UPDATE (Prefix Announcement)

    AS64511 advertises 203.0.113.0/24. Hosting AS64511 sends BGP UPDATE carrying NLRI 203.0.113.0/24 and AS_PATH [64511].

  4. Path Selection & Propagation

    AS64510 prepends ASN & forwards. Transit AS64510 prepends 64510 -> AS_PATH [64510, 64511] and compares against direct link.

Is BGP secure? Common attacks and defenses

  • BGP Prefix Hijacking. A rogue AS announces a more-specific IP prefix it does not own, blackholing or intercepting global traffic. Defense: Sign Route Origin Authorizations (ROAs) with RPKI and enforce IRR/MANRS route filtering.

Frequently asked questions about BGP

Which TCP port does BGP use for peering sessions?

Answer: 179. BGP runs over TCP port 179 for reliable incremental route updates.

How does BGP prevent routing loops between Autonomous Systems?

Answer: By rejecting routes whose AS_PATH already contains its own ASN. If a router sees its own ASN in the AS_PATH attribute, it discards the UPDATE.

Which BGP message advertises or withdraws IP prefixes?

Answer: UPDATE. UPDATE messages carry withdrawn routes, path attributes, and NLRI prefixes.

What technology cryptographically validates that an ASN is authorized to originate a prefix?

Answer: RPKI (Resource Public Key Infrastructure). RPKI ROAs bind IP prefixes to authorized origin ASNs.

In BGP best-path selection (assuming equal Local Pref), which attribute is normally preferred?

Answer: Shortest AS_PATH. BGP prefers shorter AS_PATHs when Local Preference is tied.
