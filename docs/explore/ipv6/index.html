IPv6 (Internet Protocol Version 6): how it works, step by step

IPv6 expands address space to 128 bits, eliminates NAT necessity, streamlines routing with a fixed 40-byte header (no header checksum), and replaces ARP with ICMPv6 Neighbor Discovery (NDP) and SLAAC.

IPv6 explained simply

IPv6 gives every grain of sand on Earth billions of unique street addresses, and lets devices automatically configure their own address without needing a middleman.

Specifications: RFC 8200: Internet Protocol, Version 6 (IPv6).

Devices in the IPv6 exchange

  • IPv6 Host (host, 2001:db8:1::10)
  • IPv6 Router (router, 2001:db8:1::1)
  • IPv6 Server (web server, 2001:db8:2::80)

How IPv6 works, step by step

  1. Router Solicitation / Advertisement

    SLAAC prefix discovery (ICMPv6 133/134). Host queries ff02::2 and Router announces prefix 2001:db8:1::/64 for stateless auto-config.

  2. Neighbor Discovery (NDP)

    Replaces IPv4 ARP using multicast. Host sends ICMPv6 Neighbor Solicitation (135) to resolve next-hop link-layer MAC.

  3. IPv6 Packet Forwarding

    Fixed 40B header, Hop Limit=64->63. IPv6 traffic flows using 128-bit addresses with Next Header chaining.

  1. ICMPv6 from 2001:db8:1::10 to 2001:db8:1::1: Router Solicitation (ff02::2) (70 bytes)
  2. ICMPv6 from 2001:db8:1::1 to 2001:db8:1::10: Router Advertisement (Prefix 2001:db8:1::/64, SLAAC) (110 bytes)
  3. ICMPv6 from 2001:db8:1::10 to 2001:db8:1::1: Neighbor Solicitation for 2001:db8:1::1 (86 bytes)
  4. ICMPv6 from 2001:db8:1::1 to 2001:db8:1::10: Neighbor Advertisement (MAC 02:42:ac:11:00:0b) (86 bytes)
  5. IPv6 from 2001:db8:1::10 to 2001:db8:2::80: IPv6 TCP SYN 2001:db8:1::10 -> 2001:db8:2::80 (86 bytes)

IPv6 security notes

  • Rogue Router Advertisement (RA Spoofing). An attacker sends fake ICMPv6 Router Advertisements to hijack default gateway routing on a LAN. Defense: Enable RA Guard on Layer 2 switches to drop RAs on untrusted access ports.

Test yourself on IPv6

How many bits is an IPv6 address?

Answer: 128 bits. IPv6 uses 128-bit addresses written as eight 16-bit hexadecimal groups.

Which mechanism replaces ARP in IPv6?

Answer: ICMPv6 Neighbor Discovery Protocol (NDP). IPv6 uses ICMPv6 Neighbor Solicitation and Advertisement instead of ARP broadcasts.

Do IPv6 routers fragment packets in transit?

Answer: No, only the source host fragments after ICMPv6 Packet Too Big. IPv6 eliminates router fragmentation for faster forwarding.
