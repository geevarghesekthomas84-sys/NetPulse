SMTP (Simple Mail Transfer Protocol): how it works, step by step

What is SMTP?

SMTP pushes outbound email from mail clients to submission servers (port 587) and between domain Mail Transfer Agents (port 25) after resolving DNS MX records.

What is SMTP, in simple words?

SMTP is the postal truck that drops letters at the recipient’s post office (found by checking the MX address book). You announce who it’s from, who it’s for, and hand over the letter.

  • Mail Server (MTA) (mail server, 198.51.100.25)

How does SMTP work, step by step?

  1. MX Record Lookup

    Find mail server for recipient domain. Sender queries DNS for the MX record of recipient.org -> mail.recipient.org (198.51.100.25).

  2. TCP + Greeting + EHLO

    220 Ready -> EHLO -> 250 Capabilities. MTA sends 220 banner; sender issues EHLO and learns STARTTLS & AUTH extensions.

  3. STARTTLS Upgrade

    Encrypt SMTP session with TLS. STARTTLS upgrades the plaintext TCP socket to encrypted TLS before transferring email content.

  4. MAIL FROM / RCPT TO / DATA

    Envelope & message body delivery. Sender transmits envelope addresses, email headers/MIME body, ending with <CRLF>.<CRLF> -> 250 OK.

IMAP (Internet Message Access Protocol (IMAP4rev1)): IMAP synchronizes mail folders, read/starred flags, and partial MIME attachments across multiple devices while keeping authoritative state on the mail server.

  2. DNS from 8.8.8.8 to 192.168.1.10: MX 10 mail.recipient.org (198.51.100.25) (98 bytes)

  5. SMTP from 192.168.1.10 to 198.51.100.25: C: STARTTLS -> TLS 1.3 Tunnel Established (180 bytes)
  6. SMTP from 192.168.1.10 to 198.51.100.25: C: MAIL FROM:<alice@example.com> / RCPT TO:<bob@recipient.org> (145 bytes)
  7. SMTP from 192.168.1.10 to 198.51.100.25: C: DATA [Subject: Hello] <CRLF>.<CRLF> (860 bytes)
  8. SMTP from 198.51.100.25 to 192.168.1.10: S: 250 2.0.0 Ok: queued as 9F81A2B (92 bytes)

Is SMTP secure? Common attacks and defenses

  • Email Spoofing & Open Relay Abuse. Plain SMTP trusts the MAIL FROM header unless authenticated, letting spammers forge sender domains. Defense: Publish SPF, DKIM, and DMARC DNS policies and require authenticated submission on port 587 with TLS.

Frequently asked questions about SMTP

Which DNS record tells an SMTP server where to deliver mail for a domain?

Answer: MX. Mail Exchanger (MX) records specify the hostnames handling email for a domain.

Which TCP port is the modern standard for authenticated client email submission?

Answer: 587. Port 587 is dedicated to authenticated MSA mail submission; port 25 is server-to-server relay.

What does the STARTTLS command do in SMTP?

Answer: Upgrades the plaintext TCP connection to TLS encryption. STARTTLS negotiates TLS encryption over the existing socket before AUTH or DATA.

Which sequence terminates an SMTP DATA message body?

Answer: A single period on its own line (<CRLF>.<CRLF>). RFC 5321 ends the DATA stream with a line containing only ".".

Which trio of DNS/email standards combats domain spoofing?

Answer: SPF, DKIM, DMARC. SPF authorizes sender IPs, DKIM cryptographically signs headers/body, and DMARC sets enforcement policy.
