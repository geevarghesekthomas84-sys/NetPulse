IP (IPv4) (Internet Protocol Version 4): how it works, step by step

IPv4 is the foundational network-layer protocol that routes packets across interconnected networks using 32-bit addresses, longest-prefix matching, TTL hop limits, and optional MTU fragmentation.

IP (IPv4) explained simply

IPv4 puts a ZIP code and street address on every envelope and gives it 64 hops to reach its destination; each post office decrements the hop counter and picks the best next road.

  • Router (router, 192.168.1.1)
  • App Server (web server, 203.0.113.10)

How IP (IPv4) works, step by step

  1. IPv4 Encapsulation

    20B Header + RFC 1071 Checksum. Host sets Src/Dst IP, TTL=64, DF flag, and computes the 16-bit IPv4 header checksum.

  2. Router LPM & TTL-1

    Longest-prefix lookup & checksum update. Router decrements TTL (64 -> 63), updates header checksum, and forwards to next hop.

  3. MTU Check / Delivery

    Packet arrives or fragments if > MTU. Packet arrives at destination; if larger than link MTU, it fragments or returns ICMP Frag Needed.

IP (IPv4) security notes

  • IP Source Spoofing. Senders can forge the 32-bit Source IP header field unless edge networks filter egress traffic. Defense: Deploy uRPF (Unicast Reverse Path Forwarding) and BCP 38 ingress filtering.

Test yourself on IP (IPv4)

How many bits are in an IPv4 address?

Answer: 32 bits. IPv4 addresses are 32-bit integers usually written as four dotted octets.

What happens at every Layer 3 router as an IPv4 packet is forwarded?

Answer: TTL is decremented by 1 and header checksum is recomputed. Routers decrement TTL to prevent infinite loops and update the IPv4 header checksum.

Which matching rule do routers use when multiple routes match a destination IP?

Answer: Longest-Prefix Match (most specific mask). LPM picks the route with the highest prefix length (e.g. /24 beats /16).
