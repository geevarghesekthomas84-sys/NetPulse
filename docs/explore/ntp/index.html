NTP (Network Time Protocol (v4)): how it works, step by step

What is NTP?

NTP synchronizes computer clocks across variable-latency networks down to milliseconds by exchanging four timestamps (T1, T2, T3, T4) to separate network delay from true clock offset.

What is NTP, in simple words?

You write down when you sent a text (T1), your friend writes when they got it (T2) and replied (T3), and you note when you got the reply (T4) so you can cancel out delivery delay and set your watch accurately.

How does NTP work, step by step?

  1. Client Transmit (T1)

    Mode 3 Client request stamps T1. Client records local originate timestamp T1 and sends 48-byte UDP/123 packet.

  2. Server Timestamps (T2, T3)

    Mode 4 Server stamps receive & transmit. Stratum-1 server records arrival T2 and departure T3 in 64-bit NTP fixed-point format.

  3. Offset Calculation (T4)

    Offset = ((T2-T1)+(T3-T4))/2. Client records T4, computes symmetric round-trip delay and slews system clock smoothly.

Is NTP secure? Common attacks and defenses

  • NTP Monlist Amplification. Legacy NTP servers responded to tiny mode-7 monlist queries with massive client lists, enabling 500x DDoS amplification. Defense: Disable `monlist`, restrict control queries, and use NTS (Network Time Security, RFC 8915).

Frequently asked questions about NTP

Which UDP port does NTP use?

Answer: 123. NTP operates over UDP port 123.

How many timestamps does NTP use to compute clock offset and network delay?

Answer: 4 (T1, T2, T3, T4). T1 (client send), T2 (server recv), T3 (server send), T4 (client recv) cancel out symmetric RTT.

What does Stratum 1 mean in NTP?

Answer: A server directly attached to an atomic/GPS reference clock. Stratum 0 is an atomic/GPS clock; Stratum 1 servers sync directly to Stratum 0.
