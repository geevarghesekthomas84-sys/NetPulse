DHCP (Dynamic Host Configuration Protocol): how it works, step by step

What is DHCP?

DHCP automatically assigns IPv4 addresses, subnet masks, default gateways, and DNS servers to devices joining a network through the 4-step DORA handshake.

What is DHCP, in simple words?

When a new kid joins class without a seat, they shout "Does anyone have a spare desk?" (Discover), the teacher points to Desk 50 (Offer), the kid says "I’ll take Desk 50!" (Request), and the teacher writes their name down (Ack).

Which devices take part in a DHCP exchange?

  • Client (0.0.0.0) (host, 0.0.0.0)
  • LAN Switch (switch, 192.168.1.2)
  • DHCP Server (dhcp server, 192.168.1.1)

How does DHCP work, step by step?

  1. DISCOVER

    Client broadcasts DHCPDISCOVER. Client with IP 0.0.0.0 sends UDP broadcast (68 -> 67) asking for any DHCP server on the LAN.

  2. OFFER

    Server offers 192.168.1.50. DHCP server reserves 192.168.1.50 from its pool and sends DHCPOFFER with subnet mask, gateway, and DNS.

  3. REQUEST

    Client accepts offered IP. Client broadcasts DHCPREQUEST confirming it accepts 192.168.1.50 from server 192.168.1.1.

  4. ACK

    Server commits lease (86400s). Server sends DHCPACK finalizing the 24-hour lease; client runs gratuitous ARP and configures eth0.

  4. DHCP from 192.168.1.2 to 0.0.0.0: DHCP Offer - Offered IP 192.168.1.50 (350 bytes)
  5. DHCP from 0.0.0.0 to 192.168.1.1: DHCP Request - Requesting 192.168.1.50 from 192.168.1.1 (348 bytes)
  6. DHCP from 192.168.1.1 to 0.0.0.0: DHCP ACK - Lease confirmed 192.168.1.50/24 (356 bytes)

Is DHCP secure? Common attacks and defenses

  • Rogue DHCP Server. An attacker answers DISCOVER faster than the real router, handing out their own IP as default gateway/DNS for MITM. Defense: Enable DHCP Snooping on switches to block DHCPOFFER packets on untrusted access ports.
  • DHCP Starvation. Flooding DISCOVER requests with spoofed MAC addresses exhausts the entire IP pool. Defense: Configure port security MAC limits and DHCP snooping rate limits.

Frequently asked questions about DHCP

What does the acronym DORA stand for in DHCP?

Answer: Discover, Offer, Request, Acknowledge. DORA represents the four standard DHCP messages: DISCOVER, OFFER, REQUEST, ACK.

Which UDP ports do DHCP servers and clients use?

Answer: 67 and 68. Servers listen on UDP port 67 and clients listen on UDP port 68.

Why does the client send DHCPREQUEST as a broadcast even after receiving an offer?

Answer: To inform all other DHCP servers whose offers were declined. Broadcasting REQUEST lets competing DHCP servers withdraw their unchosen offers.

Which switch feature defends against rogue DHCP servers?

Answer: DHCP Snooping. DHCP Snooping drops server-side DHCP messages arriving on untrusted user ports.

What happens if no DHCP server responds on a Windows/macOS host?

Answer: The host assigns an APIPA link-local IP (169.254.x.x). RFC 3927 APIPA assigns a 169.254.0.0/16 address when DHCP times out.
