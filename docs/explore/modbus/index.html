Modbus (Modbus TCP (Industrial Control / SCADA)): how it works, step by step

Modbus TCP (port 502) is the ubiquitous industrial automation protocol used by SCADA HMIs to poll sensors and write actuator registers on PLCs. By design, classic Modbus has zero authentication or encryption.

Modbus explained simply

Modbus is a super simple factory language where a control screen asks a robot controller: "Read dial #40001" or "Set valve #40002 to 75%."

Modbus at a glance

OSI layerLayer 7 (Industrial OT)
Default port502
TransportTCP
Data format7-byte MBAP Header + Function Code + Register Data
Common methodsFC 01 Read Coils, FC 03 Read Holding Registers, FC 06 Write Single Register, FC 16 Write Multiple

Specifications: Modbus TCP: Modbus Messaging on TCP/IP.

Devices in the Modbus exchange

  • SCADA HMI (host, 10.10.1.5)
  • OT Firewall (firewall, 10.10.1.1)
  • Industrial PLC (plc, 10.10.2.50)

How Modbus works, step by step

  1. TCP Connect to Port 502

    SCADA HMI connects to PLC. HMI opens TCP session through OT segmentation firewall to PLC port 502.

  2. FC 03 Read Holding Registers

    Read temperature & pressure registers. HMI sends MBAP header + Function Code 03 to read 2 holding registers.

  3. FC 06 Write Setpoint

    Write valve setpoint register. HMI updates Holding Register 0x0001 = 0x01F4 (500 RPM); PLC echoes confirmation.

What Modbus looks like on the wire

This is the packet sequence NetPulse replays for a typical Modbus exchange. Open the animation to inspect each one.

  1. TCP from 10.10.1.5 to 10.10.2.50: 54600 -> 502 [SYN] Connect PLC (66 bytes)
  2. Modbus/TCP from 10.10.1.5 to 10.10.2.50: Query: Trans=1, Unit=1, FC=03 Read Holding Regs (Addr=0, Qty=2) (66 bytes)
  3. Modbus/TCP from 10.10.2.50 to 10.10.1.5: Response: FC=03 Reg[0]=72°C, Reg[1]=101kPa (67 bytes)
  4. Modbus/TCP from 10.10.1.5 to 10.10.2.50: Query: FC=06 Write Single Register (Addr=1, Val=500) (66 bytes)
  5. Modbus/TCP from 10.10.2.50 to 10.10.1.5: Response: FC=06 Write Confirmed (Val=500) (66 bytes)

Modbus security notes

  • Unauthenticated PLC Register Manipulation. Classic Modbus TCP has no auth—anyone who can reach port 502 can stop motors or alter setpoints. Defense: Segment OT networks behind strict industrial firewalls (Purdue Model) and use Modbus TCP Security (TLS).

Test yourself on Modbus

Which TCP port does Modbus TCP use?

Answer: 502. Modbus TCP uses IANA well-known port 502.

Why must Modbus PLCs never be exposed directly to the public internet?

Answer: Classic Modbus TCP has zero built-in authentication or encryption. Anyone able to send packets to TCP/502 can issue read/write commands to the PLC.

What does Modbus Function Code 03 do?

Answer: Read Holding Registers. FC 03 reads contiguous 16-bit holding registers.
