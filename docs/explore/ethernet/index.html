Ethernet / ARP (IEEE 802.3 Ethernet & Address Resolution Protocol): how it works, step by step

Ethernet frames carry packets across local links using 48-bit MAC addresses. Switches dynamically learn MAC-to-port mappings, while ARP maps IPv4 addresses to MAC addresses.

Open the interactive Ethernet / ARP animation to watch each packet move and inspect its headers.

Ethernet / ARP explained simply

IP addresses are like names on an envelope, while MAC addresses are the exact apartment mailbox numbers in the building. ARP shouts "Who lives in 192.168.1.20?" so the mail carrier knows which mailbox to use.

Ethernet / ARP at a glance

OSI layerLayer 2 (Data Link) / Network Access
Default portN/A (EtherType 0x0800 / 0x0806 / 0x8100)
TransportPhysical Media (Cat6 / Fiber)
Data format14-byte Frame Header + 46–1500B Payload + 4B FCS
Common methodsARP Request, ARP Reply, Unicast Frame, 802.1Q VLAN Tag

Specifications: RFC 826: Ethernet Address Resolution Protocol (ARP); IEEE 802.3: Ethernet Standard.

Devices in the Ethernet / ARP exchange

  • Laptop A (host, 192.168.1.10)
  • Switch (8 ports) (switch, 192.168.1.2)
  • File Server (file server, 192.168.1.20)
  • Printer / Host C (tv box, 192.168.1.30)

How Ethernet / ARP works, step by step

  1. ARP Broadcast

    Who has 192.168.1.20? -> ff:ff:ff:ff:ff:ff. Laptop A needs File Server’s MAC address and emits an Ethernet broadcast ARP Request.

  2. Switch Flood & Learn

    Switch learns MAC-A on Port 1 & floods. Switch records 02:42:ac:11:00:10 on Port 1 and floods the broadcast frame to Ports 2 and 3.

  3. ARP Unicast Reply

    File Server replies with its MAC address. File Server sends an ARP Reply directly to Laptop A’s MAC; Switch learns MAC-B on Port 2.

  4. Unicast Ethernet Frame

    Switched directly Port 1 -> Port 2. Subsequent Ethernet frames (802.1Q / IPv4) are forwarded only to Port 2, never flooded to Host C.

  4. ARP from 192.168.1.20 to 192.168.1.10: 192.168.1.20 is at 02:42:ac:11:00:20 (60 bytes)
  5. ARP from 192.168.1.2 to 192.168.1.10: Unicast Port 1: 192.168.1.20 is at 02:42:ac:11:00:20 (60 bytes)
  6. Ethernet from 192.168.1.10 to 192.168.1.2: 802.1Q VLAN 10 Unicast Frame -> 02:42:ac:11:00:20 (128 bytes)
  7. Ethernet from 192.168.1.2 to 192.168.1.20: Switched directly Port 1 -> Port 2 (Host C sees nothing) (128 bytes)

Ethernet / ARP security notes

  • ARP Spoofing / Cache Poisoning. An attacker sends unsolicited ARP replies claiming to own the gateway’s IP, intercepting all LAN traffic (MITM). Defense: Enable Dynamic ARP Inspection (DAI) with DHCP Snooping on managed switches.
  • MAC Flooding. Overflowing a switch’s CAM table forces it to fail open as a hub and flood all frames. Defense: Enforce Port Security limiting learned MACs per switchport.

Test yourself on Ethernet / ARP

Which MAC address is used for an Ethernet broadcast frame (like ARP Request)?

Answer: ff:ff:ff:ff:ff:ff. All-ones (ff:ff:ff:ff:ff:ff) instructs switches to flood the frame out every port in the broadcast domain.

How does an Ethernet switch learn which port a device is connected to?

Answer: By inspecting the source MAC address of incoming frames. Switches inspect the Source MAC field of every arriving frame and bind it to the ingress port.

What is the EtherType value for ARP?

Answer: 0x0806. 0x0806 identifies ARP, 0x0800 identifies IPv4, 0x86DD identifies IPv6, and 0x8100 identifies 802.1Q VLAN.

What is the standard maximum payload (MTU) of an untagged Ethernet II frame?

Answer: 1500 bytes. Standard Ethernet II supports a 1500-byte payload MTU.

Which switch security feature prevents ARP spoofing?

Answer: Dynamic ARP Inspection (DAI). DAI validates ARP packets against trusted DHCP snooping bindings.
