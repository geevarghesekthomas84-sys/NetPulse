RADIUS (Remote Authentication Dial-In User Service (802.1X)): how it works, step by step

What is RADIUS?

RADIUS centralizes Authentication, Authorization, and Accounting (AAA) for enterprise 802.1X Wi-Fi/wired switches and VPNs, bridging client EAPOL messages to an identity directory.

What is RADIUS, in simple words?

When you plug into an office port or join corporate Wi-Fi, the switch acts like a security guard calling HQ (the RADIUS server) to check your employee badge before opening the gate.

How does RADIUS work, step by step?

  1. EAPOL Start & Identity

    Supplicant sends EAP-Identity to Authenticator AP. 802.1X supplicant connects; AP keeps port unauthorized and requests EAP identity.

  2. RADIUS Access-Request & Challenge

    AP relays EAP inside UDP/1812 to RADIUS. AP wraps EAP payload into RADIUS Access-Request; RADIUS replies Access-Challenge (EAP-TLS).

  3. Access-Accept & Port Open

    RADIUS approves VLAN + MSK key. RADIUS returns Access-Accept with Master Session Key and assigned VLAN; AP authorizes port.

Is RADIUS secure? Common attacks and defenses

  • BlastRADIUS (MD5 Collision Forgery). Legacy RADIUS over UDP relies on MD5 Response Authenticator without Message-Authenticator. Defense: Require Message-Authenticator (RFC 3579) on all packets or run RadSec (RADIUS over TLS, port 2083).

Frequently asked questions about RADIUS

Which UDP port does RADIUS use for authentication?

Answer: 1812. RADIUS uses UDP 1812 for authentication/authorization and 1813 for accounting.

In 802.1X, what are the three architectural roles?

Answer: Supplicant, Authenticator (Switch/AP), Authentication Server (RADIUS). The Supplicant (device) authenticates via the Authenticator (AP/switch) to the RADIUS server.

Which modern extension protects RADIUS traffic with TLS?

Answer: RadSec (TCP 2083). RadSec (RFC 6614) wraps RADIUS inside TLS to eliminate MD5 vulnerabilities.

Which protocols are related to RADIUS?

  • TLS / SSL: Transport Layer Security (TLS 1.3)
  • HTTP Proxy: HTTP Forward Proxy & CONNECT Tunnel
  • SOCKS5: SOCKS Protocol Version 5
  • Reverse Proxy: Reverse Proxy & Load Balancer (TLS Termination)
  • WireGuard: WireGuard Modern Cryptographic VPN
  • IPsec: Internet Protocol Security (IKEv2 + ESP)
