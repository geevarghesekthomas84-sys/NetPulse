DNSSEC (Domain Name System Security Extensions): how it works, step by step

DNSSEC adds cryptographic digital signatures (RRSIG) and a hierarchical chain of trust (Root -> TLD DS -> Zone DNSKEY) so validating resolvers detect forged or poisoned DNS answers—note it ensures authenticity, not encryption.

DNSSEC explained simply

DNSSEC is a wax royal seal on the phonebook page: anyone can still read the number, but nobody can fake it without breaking the seal.

DNSSEC at a glance

OSI layerLayer 7 (DNS Integrity & Authenticity)
Default port53
TransportUDP (EDNS0) / TCP
Data formatDNS RRSIG, DNSKEY, DS, NSEC/NSEC3 Records
Common methodsDO Flag (DNSSEC OK), RRSIG Verification, DNSKEY + DS Chain of Trust

Specifications: RFC 4033: DNS Security Introduction and Requirements.

Devices in the DNSSEC exchange

  • Client (host, 192.168.1.10)
  • Validating Resolver (dns server, 8.8.8.8)
  • Signed Auth NS (dns server, 198.51.100.53)

How DNSSEC works, step by step

  1. Query with DO=1

    Resolver requests DNSSEC signatures. Validating resolver sets EDNS0 DO (DNSSEC OK) bit requesting RRSIG signatures.

  2. Signed Answer + DNSKEY/DS

    Auth returns A record + RRSIG signature. Authoritative server returns A 203.0.113.10 paired with RRSIG signed by ZSK/KSK.

  3. Chain Verification (AD=1)

    Verify Root -> TLD DS -> Zone DNSKEY. Resolver verifies signature against DS hash in parent zone and sets AD=1 (Authenticated Data).

DNSSEC security notes

  • Zone Enumeration via NSEC. Standard NSEC records allow walking every subdomain in a zone. Defense: Use hashed NSEC3 records with opt-out to prevent easy zone walking.

Test yourself on DNSSEC

Does DNSSEC encrypt DNS queries from eavesdroppers?

Answer: No, DNSSEC provides cryptographic authenticity/integrity, not encryption. DNSSEC prevents tampering/spoofing via signatures; DoH/DoT provide privacy encryption.

Which DNSSEC record holds the digital signature for a record set?

Answer: RRSIG. RRSIG holds the cryptographic signature covering an RRset.

What does a validating resolver return when a DNSSEC signature fails verification?

Answer: SERVFAIL. Bogus DNSSEC responses trigger SERVFAIL to protect clients from poisoned data.
