IMAP (Internet Message Access Protocol (IMAP4rev1)): how it works, step by step

IMAP synchronizes mail folders, read/starred flags, and partial MIME attachments across multiple devices while keeping authoritative state on the mail server.

Open the interactive IMAP animation to watch each packet move and inspect its headers.

IMAP explained simply

IMAP is a shared cloud library: your phone, laptop, and tablet all look at the same folders and see immediately when you read or star a message.

IMAP at a glance

OSI layerLayer 7 (Application)
Default port143 (Plain), 993 (IMAPS/TLS)
TransportTCP
Data formatTagged Bidirectional Commands + MIME Body Parts
Common methodsLOGIN, SELECT INBOX, FETCH, UID SEARCH, IDLE, LOGOUT

Specifications: RFC 9051: IMAP4rev2.

Devices in the IMAP exchange

  • Client (host, 192.168.1.10)
  • Gateway (router, 192.168.1.1)
  • Server (mail server, 198.51.100.25)

How IMAP works, step by step

  1. IMAPS TLS + LOGIN

    Connect port 993 & authenticate. Client establishes TLS on port 993 and logs in with tagged command a001.

  2. SELECT & FETCH Headers

    Fetch mailbox UIDs & subject lines only. Client inspects folder unread flags and fetches only headers before downloading attachments.

  3. IDLE Push Notification

    Server pushes * EXISTS on new mail. IMAP IDLE keeps the socket open for instant real-time new email alerts.

What IMAP looks like on the wire

  1. IMAP from 192.168.1.10 to 198.51.100.25: a001 LOGIN alice **** (over IMAPS 993) (110 bytes)
  2. IMAP from 198.51.100.25 to 192.168.1.10: a001 OK Logged in (94 bytes)
  3. IMAP from 192.168.1.10 to 198.51.100.25: a002 SELECT INBOX -> a003 FETCH 1:5 (FLAGS ENVELOPE) (120 bytes)
  4. IMAP from 198.51.100.25 to 192.168.1.10: * 5 EXISTS, FETCH envelopes returned (840 bytes)
  5. IMAP from 192.168.1.10 to 198.51.100.25: a004 IDLE (Waiting for push mail) (72 bytes)

IMAP security notes

  • Plaintext IMAP Credential Theft. Port 143 without STARTTLS leaks credentials. Defense: Enforce IMAPS (TLS port 993) and OAuth2/XOAUTH2 tokens.

Test yourself on IMAP

Which ports are standard for IMAP and IMAPS (TLS)?

Answer: 143 and 993. IMAP uses 143 (STARTTLS) and 993 (IMAPS implicit TLS).

Which IMAP command enables real-time push notifications without polling?

Answer: IDLE. RFC 2177 IDLE lets the server push `* N EXISTS` immediately when mail arrives.

Can IMAP download just an email’s headers without downloading a 20MB attachment?

Answer: Yes, via partial BODYSTRUCTURE/FETCH. IMAP allows fetching headers or individual MIME parts on demand.
