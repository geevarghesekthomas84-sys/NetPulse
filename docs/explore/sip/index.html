SIP (Session Initiation Protocol (VoIP Signaling)): how it works, step by step

What is SIP?

SIP sets up, modifies, and tears down voice and video VoIP calls (INVITE / 180 Ringing / 200 OK / ACK) while actual voice packets travel separately over RTP.

What is SIP, in simple words?

SIP is the telephone operator that rings the other phone ("INVITE", "Ringing!", "Picked up!"), and once connected, both people talk directly over RTP.

How does SIP work, step by step?

  1. INVITE -> 180 Ringing

    Caller sends INVITE with SDP codecs. Phone A sends SIP INVITE via SIP Proxy; Phone B alerts user with 180 Ringing.

  2. 200 OK & ACK

    Call answered; media parameters agreed. Phone B answers with 200 OK; Phone A confirms with ACK.

  3. RTP Media & BYE

    Voice flows over RTP; BYE hangs up. Bidirectional RTP audio packets flow directly until one party sends SIP BYE.

SIP (Session Initiation Protocol (VoIP Signaling)): SIP sets up, modifies, and tears down voice and video VoIP calls (INVITE / 180 Ringing / 200 OK / ACK) while actual voice packets travel separately over RTP. RTSP (Real Time Streaming Protocol (CCTV / IP Cameras)): RTSP acts as a "network remote control" on port 554 for IP cameras and media servers (DESCRIBE -> SETUP -> PLAY -> TEARDOWN), while video frames stream over RTP.

Is SIP secure? Common attacks and defenses

  • SIP Toll Fraud & Eavesdropping. Unencrypted SIP on port 5060 leaks caller IDs and credentials; weak PBX auth allows expensive international call hijack. Defense: Use SIPS (TLS on port 5061) and SRTP for voice media.

Frequently asked questions about SIP

Which ports does SIP use for plaintext and TLS signaling?

Answer: 5060 and 5061. SIP uses 5060 (UDP/TCP) and SIPS uses 5061 (TLS).

Which protocol carries the actual voice audio after SIP establishes the call?

Answer: RTP. SIP is signaling only; RTP (Real-time Transport Protocol) carries audio/video.

Which SIP message ends an active call?

Answer: BYE. SIP uses BYE to tear down an established dialog.
