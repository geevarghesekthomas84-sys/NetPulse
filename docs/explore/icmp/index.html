ICMP (Internet Control Message Protocol (Ping & Traceroute)): how it works, step by step

What is ICMP?

ICMP delivers network-layer diagnostics and error reporting. Tools like ping (Echo Request/Reply) and traceroute (TTL expiration probes) rely on ICMP control messages.

What is ICMP, in simple words?

ICMP is like shouting "Marco!" across a canyon and timing how fast "Polo!" bounces back—or having each relay runner tell you when your message ran out of steps.

Which devices take part in a ICMP exchange?

  • Client (host, 192.168.1.10)
  • Home Router (router, 192.168.1.1)
  • ISP AS64500 (router, 100.64.0.1)
  • Web Server (web server, 203.0.113.10)

How does ICMP work, step by step?

  1. Echo Request (Ping)

    Type 8 Echo Request reaches target. Client sends ICMP Type 8 Echo Request (TTL=64) across two routers to 203.0.113.10.

  2. Echo Reply

    Type 0 Echo Reply measures RTT. Web Server replies with ICMP Type 0 Echo Reply; Client calculates round-trip latency.

  3. Traceroute Hop 1 (TTL=1)

    Router 1 decrements TTL to 0 -> Time Exceeded. Traceroute sends TTL=1; Home Router drops it and returns ICMP Type 11 Time Exceeded.

  4. Traceroute Hop 2 (TTL=2)

    ISP Router returns Time Exceeded. Client increments TTL=2; ISP Router reveals its hop IP via ICMP Type 11.

  5. Destination Reached

    TTL=3 reaches 203.0.113.10. Final probe arrives at destination which returns Echo Reply / Port Unreachable.

Is ICMP secure? Common attacks and defenses

  • Smurf Amplification & Ping Flood. Sending ICMP Echo Requests to a subnet broadcast address with a spoofed source IP floods the victim. Defense: Disable directed broadcast forwarding on routers and rate-limit ICMP responses.
  • ICMP Tunneling. Covert channels hide arbitrary C2 data inside the Echo payload when firewalls block TCP/UDP. Defense: Inspect ICMP payload sizes and disallow anomalous non-standard Echo payloads.

Frequently asked questions about ICMP

Which ICMP Type/Code is returned when a router decrements IP TTL to 0?

Answer: Type 11 Time Exceeded. Routers emit ICMP Type 11 Code 0 (TTL exceeded in transit) whenever TTL reaches zero.

How does traceroute discover every router hop along a path?

Answer: By sending probes with incrementing TTL (1, 2, 3...). Each router along the path drops the probe when TTL hits 0 and reveals itself via Time Exceeded.

Why shouldn’t firewalls blindly block ALL ICMP?

Answer: It breaks Path MTU Discovery (Type 3 Code 4). Blocking ICMP Fragmentation Needed causes PMTUD blackholes on links with smaller MTUs.

What IP protocol number identifies ICMP inside an IPv4 header?

Answer: 1. Protocol 1 is ICMP, 6 is TCP, and 17 is UDP.

Which ICMP message pair does `ping` use?

Answer: Type 8 and Type 0. Ping sends Type 8 Echo Request and expects Type 0 Echo Reply.
