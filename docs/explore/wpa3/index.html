WPA3 (Wi-Fi Protected Access 3 (SAE Dragonfly)): how it works, step by step

What is WPA3?

WPA3 replaces WPA2’s vulnerable PSK derivation with SAE (Dragonfly) password-authenticated key exchange, providing forward secrecy and neutralizing offline dictionary cracking, plus mandatory Protected Management Frames (PMF).

What is WPA3, in simple words?

In WPA3, even if a hacker records your entire Wi-Fi login, they cannot test password guesses at home—they only get one live try per connection with the router.

How does WPA3 work, step by step?

  1. SAE Commit (Dragonfly)

    Scalar + Elliptic Curve Element exchange. STA and AP exchange Dragonfly Commit messages derived from password + elliptic curve.

  2. SAE Confirm

    Zero-knowledge proof of shared PMK. Both verify Confirm tokens, proving both know the passphrase with Forward Secrecy.

  3. 4-Way Handshake + PMF

    Install AES-CCMP/GCMP keys + 802.11w PMF. Protected Management Frames block spoofed deauthentication floods.

Frequently asked questions about WPA3

What key exchange replaces PSK in WPA3-Personal?

Answer: SAE (Dragonfly). Simultaneous Authentication of Equals (SAE / Dragonfly) resists offline brute force.

What does mandatory PMF (802.11w) in WPA3 prevent?

Answer: Unauthenticated deauthentication/disassociation attacks. Protected Management Frames sign management frames so attackers cannot kick clients off Wi-Fi.

Does WPA3-SAE provide Forward Secrecy?

Answer: Yes, every SAE session produces a fresh ephemeral PMK. Even if the Wi-Fi password leaks later, previously captured sessions cannot be decrypted.
