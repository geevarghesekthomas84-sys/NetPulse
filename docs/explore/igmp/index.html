IGMP (Internet Group Management Protocol (v3)): how it works, step by step

What is IGMP?

IGMP lets IPv4 hosts join and leave IP multicast groups (224.0.0.0/4) so routers and IGMP-snooping switches only forward live video/IPTV streams to interested receivers.

What is IGMP, in simple words?

Instead of mailing 1,000 copies of a TV broadcast to everyone on the street, IGMP lets houses put up a flag saying "Deliver Channel 5 here!"

How does IGMP work, step by step?

  1. Router Query

    Router polls 224.0.0.1 for active listeners. Multicast router sends periodic IGMP General Query to all-hosts 224.0.0.1.

  2. Host Join Report

    Host joins multicast group 239.1.1.5. TV Box / Client sends IGMPv3 Membership Report joining 239.1.1.5.

  3. Multicast Stream & Leave

    Stream flows until host sends Leave. Server streams multicast UDP to 239.1.1.5; host later sends Leave to prune traffic.

Is IGMP secure? Common attacks and defenses

  • IGMP Flooding / Rogue Group Join. An attacker joins many multicast streams to saturate switch/access links. Defense: Enable IGMP Snooping and limit max multicast groups per switch port.

Frequently asked questions about IGMP

What is the IPv4 multicast address range?

Answer: 224.0.0.0/4. 224.0.0.0 through 239.255.255.255 (Class D) is reserved for IPv4 multicast.

What does IGMP Snooping on a switch prevent?

Answer: Multicast flooding out ports with no interested listeners. IGMP snooping listens to Join/Leave messages so multicast only goes to subscribed ports.

Which IP protocol number does IGMP use?

Answer: 2. IGMP uses IPv4 protocol number 2.
