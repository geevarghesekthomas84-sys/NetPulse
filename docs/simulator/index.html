Network simulator: a Packet Tracer-style workbench in your browser

Drag routers, switches, PCs, servers and firewalls onto a canvas, cable them together and watch traffic flow. Every device behaves like the real thing, and changes you make from the command line take effect immediately.

What the simulator can do

  • IOS-style command line. User, privileged and configuration modes, ? help, tab completion and no forms. Configure interfaces, VLANs, static routes, OSPF, RIP and BGP with network statements, NAT and access lists, and read results with show ip route, show vlan brief, show running-config and more.
  • DHCP. Servers on routers or dedicated hosts, relay across routers with ip helper-address, and a PC desktop with IP configuration.
  • Test packets (PDUs). Send ICMP, TCP or UDP between any two devices and follow every event hop by hop.
  • Troubleshooting. Shut an interface, cut a cable or add a firewall rule and see what breaks.

20 guided labs

  1. Home Network (NAT/DHCP -> ISP -> Web) (Foundations): Home PC connects through a Wi-Fi NAT/DHCP router and ISP to reach a public web server.
  2. Two LANs Joined by a Router (Routing): Connect Subnet A (192.168.1.0/24) and Subnet B (192.168.2.0/24) across a static router.
  3. VLANs & Inter-VLAN Routing (Switching): Separate Engineering (VLAN 10) and Finance (VLAN 20) on one switch with Router-on-a-Stick.
  4. DNS Hierarchy (Root -> TLD -> Auth) (Core Services): Trace recursive vs iterative resolution with TTL caching across Root, .com TLD, and Authoritative servers.
  5. DHCP DORA with Relay Across Router (Core Services): Client on Subnet A obtains an IP from a centralized DHCP server on Subnet B via IP Helper relay.
  6. NAT / PAT Port Translation (Routing): Multiple private LAN hosts share one public WAN IP (198.51.100.1) using distinct source ports.
  7. Firewall + DMZ Web Server (Security): External Internet may access DMZ Web (:80/:443) but is blocked from reaching internal LAN DB (:5432).
  8. HTTP vs HTTPS Sniffing on Shared Hub (Security): Compare plaintext HTTP credentials vs TLS 1.3 encrypted HTTPS packets on a shared Layer 1 Hub.
  9. TCP Congestion Control (Sawtooth cwnd) (Transport): Run an iPerf transfer across a lossy 10% link and watch Slow Start + Reno/CUBIC cwnd sawtooth.
  10. SYN Flood & SYN Cookies Defense (Security): Observe half-open SYN_RCVD exhaustion during a SYN burst and how SYN Cookies neutralize it.
  11. ARP Spoofing / MITM & DAI Detection (Security): Attacker injects forged ARP replies to intercept traffic between Victim PC and Gateway.
  12. DNS Cache Poisoning & DNSSEC Fix (Security): Compare unsigned DNS cache poisoning against cryptographic RRSIG validation in DNSSEC.
  13. BGP 3-AS Peering & Failover (Routing): Three Autonomous Systems exchange prefixes; break primary link and watch BGP re-converge.
  14. Site-to-Site WireGuard VPN Tunnel (Security): Connect Office A (10.1.0.0/24) to Office B (10.2.0.0/24) over an encrypted UDP/51820 tunnel.
  15. Reverse Proxy & 3-Backend Load Balancer (Architecture): Distribute HTTPS requests across 3 backend workers and survive a node power-off.
  16. Wi-Fi WPA2 / Captive Portal / RADIUS (Wireless): Phone associates to Access Point, authenticates via RADIUS 802.1X, and reaches the web.
  17. End-to-End Mail Flow (SMTP + MX + IMAP) (Application): Sender resolves MX record, delivers via SMTP, and recipient picks up mail via IMAP.
  18. Industrial OT Network & Modbus PLC (OT / ICS): Segment SCADA HMI and Modbus TCP PLC (port 502) behind an OT firewall.
  19. Routing Loop & TTL Expiry (Troubleshooting): Misconfigured static routes bounce packets between R1 and R2 until TTL hits 0.
  20. MTU Mismatch & IP Fragmentation / PMTUD (Troubleshooting): A 576-byte tunnel link sits in the path; send a 1400-byte ping and watch PMTUD / fragmentation.
