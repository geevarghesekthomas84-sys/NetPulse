NetPulse: watch the internet work, then build your own network

NetPulse is a free, interactive way to learn how computer networks work. Watch real protocol exchanges packet by packet, inspect every byte, and build and break networks in a Packet Tracer-style simulator. It runs in your browser with no sign-up and no tracking, in English, Spanish, Arabic, Hindi, Malayalam and Tamil.

What you can do

  • Explore 39 protocols. DNS, TCP, TLS, HTTP, BGP, DHCP and more, as step-by-step animations with plain-English notes. See all protocols.
  • Inspect packets. A Wireshark-style inspector shows headers, flags and a colour-coded hex dump. You can also open your own .pcap files locally.
  • Build networks. Cable routers, switches and PCs in the network simulator, configure them from an IOS-style command line, and send test packets.
  • Practise. 20 guided labs, quizzes, troubleshooting challenges and a daily streak in Learn.

Popular protocols

  • HTTP: Hypertext Transfer Protocol
  • DNS: Domain Name System
  • TCP: Transmission Control Protocol
  • TLS / SSL: Transport Layer Security (TLS 1.3)
  • DHCP: Dynamic Host Configuration Protocol
  • BGP: Border Gateway Protocol (BGP-4)
  • UDP: User Datagram Protocol
  • IP (IPv4): Internet Protocol Version 4
  • ICMP: Internet Control Message Protocol (Ping & Traceroute)
  • SSH: Secure Shell Protocol (SSH-2)
