The 4 Stages of DNS Resolution

1. Recursive Resolver (ISP / 8.8.8.8 / 1.1.1.1)

The client computer queries its configured recursive DNS server. If not cached, the resolver starts the query chain.

2. Root Nameserver (.)

The resolver contacts one of the 13 root server IP clusters. The root server directs the resolver to the appropriate TLD (.com, .org, .net).

3. TLD Nameserver (.com)

The Top-Level Domain server returns the NS records for the domain's authoritative nameserver (e.g. Cloudflare, Route 53).

4. Authoritative Nameserver

The authoritative server holds the final DNS record (A, AAAA, CNAME) and delivers the destination IP address back to the resolver.
