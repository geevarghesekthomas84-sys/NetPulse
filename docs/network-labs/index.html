Featured Diagnostic Missions:

Mission 1: The Severed Uplink Beginner

The office PC cannot reach the corporate web server. Inspect physical link states, identify the severed cable, and reconnect the router.

Mission 2: The Rogue Gateway Beginner

Packets are dropping immediately upon leaving the host. Diagnose the incorrect default gateway IP and restore routing.

Mission 3: Blackhole Routing Intermediate

The core router has a broken static route pointing traffic into a blackhole. Inspect routing tables and re-point the next-hop gateway.

A host with a restrictive /28 mask cannot broadcast to its /24 default gateway. Fix the bitmask mismatch to restore connectivity.

Mission 5: Missing DNS Authority Advanced

Web pings fail by domain name while raw IP pings succeed. Reconfigure the host's primary DNS server IP to restore name resolution.
