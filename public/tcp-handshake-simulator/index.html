How the TCP 3-Way Handshake Works (Step-by-Step)

1

Client → Server: SYN (Synchronize)

The client picks an Initial Sequence Number (ISN = 1000) and sends a segment with the SYN=1 control flag set. The client enters SYN_SENT state.

2

Server → Client: SYN-ACK (Synchronize-Acknowledge)

The server allocates buffers, chooses its own ISN = 5000, acknowledges client's sequence with ACK = 1001 (ISN + 1), and sets SYN=1, ACK=1. Server enters SYN_RCVD state.

3

Client → Server: ACK (Acknowledge)

The client sends ACK = 5001 to acknowledge the server's SYN. Both sides transition to ESTABLISHED state and reliable full-duplex data transmission begins!
