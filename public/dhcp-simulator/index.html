⚡ Open Interactive DHCP Simulator
D

Discover

Client broadcasts UDP message on port 67 looking for available DHCP servers.

O

Offer

DHCP Server reserves an available IP and replies with subnet mask and default gateway.

R

Request

Client broadcasts its acceptance of the offered IP address so other servers release theirs.

A

Acknowledge

Server sends final ACK packet committing the lease and client binds the IP.
